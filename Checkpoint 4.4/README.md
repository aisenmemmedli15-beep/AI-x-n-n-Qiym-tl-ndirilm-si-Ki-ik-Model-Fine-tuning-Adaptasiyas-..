# Layihənin Məqsədi
Bu layihənin məqsədi Süni İntellekt (LLM) və RAG (Retrieval-Augmented Generation) sistemlərində qarşılaşan uğursuzluq hallarını (failure cases) sistematik şəkildə izləmək, xətaların əsas səbəblərini (kök-səbəb analizi) müəyyənləşdirmək və sistemin optimallaşdırılması üçün texniki həll yollarını sənədləşdirməkdir.
# Layihə Haqqında Məlumat
Sistem ən çox rast gəlinən 3 ana uğursuzluq ssenarisini təhlil edir:
1. **Zəif Retrieval (Poor Retrieval):** Vektor verilənlər bazasından yanlış və ya natamam kontekstin götürülməsi.
2. **Zəif Prompt (Poor Prompting):** Sistem təlimatlarının qeyri-dəqiq olması səbəbindən keyfiyyətsiz və ya qeyri-strukturlaşdırılmış cavabların alınması.
3. **Qeyri-müəyyən Sual (Ambiguous Query):** İstifadəçi tərəfindən kifayət qədər kontekst təqdim edilməməsi nəticəsində modelin yanlış ehtimallar etməsi
