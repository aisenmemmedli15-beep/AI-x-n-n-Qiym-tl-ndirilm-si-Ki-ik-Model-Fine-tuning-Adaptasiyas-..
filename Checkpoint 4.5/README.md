# Layihənin Məqsədi
Bu layihənin məqsədi əvvəlki mərhələdə müəyyən olunmuş "Zəif Prompt / System Instruction" uğursuzluq kateqoriyasını **Few-Shot Prompting** və **Strukturlaşdırılmış Çıxış Təlimatları** vasitəsilə həll etmək və optimallaşdırmanın effekti üçün "Əvvəl və Sonra" (Before/After) müqayisəli qiymətləndirməsini aparmaqdır.

# Layihə Haqqında Məlumat
Sistem iki fərqli mərhələni müqayisə edir:
1. **Düzəlişdən Əvvəl (Baseline):** Uğursuz və ümumi cavablar verən baza prompt.
2. **Düzəlişdən Sonra (Optimized Few-Shot):** Nümunələrlə zənginləşdirilmiş, başlıq və maddələrlə cavab qaytaran optimallaşdırılmış prompt.
