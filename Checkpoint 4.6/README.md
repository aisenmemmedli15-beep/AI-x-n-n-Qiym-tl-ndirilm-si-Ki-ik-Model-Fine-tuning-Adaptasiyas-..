# Layihənin Məqsədi
Bu layihənin məqsədi LLM və RAG sistemləri üzrə aparılmış qiymətləndirmə metodologiyasını, kök-səbəb analizlərini, edilən optimallaşdırmaları və onların yekun nəticələrini vahid yazılı hesabat şəklində təqdim etməkdir.

# Layihə Haqqında Məlumat
Sistem bütün checkpoint-lər üzrə toplanmış məlumatları təhlil edir:
1. **Qiymətləndirmə Metodologiyası:** Pass-Rate, Orta Latency və Token xərclərinin hesablanma prinsipləri.
2. **Kök-Səbəb Analizi:** Retrieval xətaları, zəif promptlar və qeyri-müəyyən sorğular üzrə nəticələr.
3. **Optimallaşdırma Effekti:** Few-Shot Prompting tətbiqindən əvvəl və sonra göstəricilərin müqayisəsi.
